Accessibility

Draft for owner review. Last updated October 2026.

We want everyone to be able to see our menu and order. This site is built to the Web Content Accessibility Guidelines (WCAG) 2.1 AA: readable contrast, keyboard navigation and labels for screen readers. Any video that plays by itself has a Pause button, and visitors who set "reduce motion" on their device see a still picture.

No formal outside audit has been done yet. If anything on this site is hard to use, call (518) 280-3288 and we will take your order by phone and fix the problem.
